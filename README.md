# conceptos de NodeJS
Este proyecto es una practica de los primeros conceptos de nodejs, donde implementaremos middlewares, endpoints y fue construido con pnpm como gestor de paquetes

## Demo del backend

Podes ver una demo del proyecto en produccion [aqui](https://retomamosbackend.vercel.app/)

## Librerias Utilizadas
-Node js v24.11 o cualquier version posterior a las 22.
-ExpressJS
-Cors 
-Morgan

##Instalacion y configuracion del proeycto

1- Clonar el repositorio
`git clone https://github.com/LMA1995/retomamosBackend`

2-Instalar las dependencias
`pnpm install`

3- Iniciar aplicacion:
```bash

#Comando de produccion
pnpm start
##comando de desarrollo
pnpm run dev
```
